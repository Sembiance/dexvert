The support binaries do not need installation or codec registration.
The converter loads only these pinned copies from its own support directory.
On Linux/other POSIX hosts they require Wine with 32-bit support; on Windows
run the supplied bridge directly. The Python converter requires no pip modules.

The exact 4096-byte harmonic-count lookup recovered from MM32DCMP is compressed
inside the Python converter. The standalone format document includes the
complete effective lookup as ranges. The synthesis tables remain in the DLLs.

Rebuild the helper from the project root:
  i686-w64-mingw32-gcc -O2 -Wall -Wextra -s -static-libgcc \
    -o voxware_support/decoder_bridge.exe voxware_support/decoder_bridge.c
Update SUPPORT_HASHES in the Python module after a deliberate rebuild.
